* Ideia do projeto:

- encapsular atributos. 

- uma classe pode ter um objeto de outra classe dentro dela.

-  organizar um código Java.

* Arquivo "Motor.java"

- Guarda info do motor:
qtdPist: Quantos pistões tem (ex: 4)
potencia: Cavalos do motor (ex: 85 cv)

* Arquivo "Veiculo.java"

- Guarda info do carro:
Placa, marca, modelo, cor
Velocidade máxima, número de rodas
Tem um motor dentro (objeto da classe 'Motor')

* Arquivo Teste.java

- Cria 5 carros.
- Expostos em uma lista organizada.
